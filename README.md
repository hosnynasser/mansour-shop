# منصور — موقع المحل

موقع محل منصور للأدوات الكهربائية والصحية (حلوان أطلس، أمام مسجد الروضة).

## إزاي تعدّل المنتجات والأسعار؟
من الموقع نفسه: زرار "لوحة التحكم" تحت في الفوتر ← كود الدخول. مفيش حاجة تانية مطلوبة للتعديل اليومي.

## لو عايز تعدّل الكود
- `src/App.tsx` — كل الموقع (الصفحات، المنتجات المبدئية، السلة، لوحة التحكم). سطر `API_BASE` فيه رابط الباك إند.
- `src/style.css` — الألوان والتنسيق.
- `src/photos/` — الصور.
- `worker/` — كود الباك إند (Cloudflare Worker) وتعليمات نشره في `worker/DEPLOY.md`.

## البناء والنشر
```
npm install
npm run build      ← الناتج في dist/
```
النشر التلقائي: الموقع متوصل بـ Cloudflare Pages — أي push على main بينزل لايف لوحده.
